# Security policy

Please report vulnerabilities in this project through GitHub's private
security advisory flow instead of a public issue. Include a minimal synthetic
reproduction and avoid submitting live credentials, personal data, or third-
party scan output.

This project is intended for systems you own or are explicitly authorized to
test. A scanner result is a lead: anonymously readable data may be intentionally
public and does not, by itself, prove that Row Level Security is disabled.
